## Prerequisites

Before diving in, ensure you have:

- A valid email address for account verification
- Access to a modern web browser like Chrome or Firefox
- Optional: GitHub account for seamless project integration

<Callout kind="info">
  COSSA is a web-based platform—no downloads required. You can start in under 5 minutes.
</Callout>

## Create and Verify Your Account

Sign up quickly to access the dashboard.

<Steps>
  <Step title="Visit the Signup Page" icon="globe">
    Navigate to [https://cossa.io/signup](https://cossa.io/signup).
  </Step>
  <Step title="Enter Your Details" icon="user-plus">
    Provide your email, full name, and create a strong password.
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your inbox for the verification link from `no-reply@cossa.io` and click it.
  </Step>
  <Step title="Log In" icon="log-in">
    Return to [https://cossa.io/login](https://cossa.io/login) and sign in.
  </Step>
</Steps>

<Callout kind="tip">
  Enable two-factor authentication during signup for added security.
</Callout>

## Join Your First Community

Explore active communities tailored for founders and investors.

<Tabs>
  <Tab title="Search Communities" icon="search">
    Use the search bar to find topics like "AI open source" or "Rust ecosystem".
    
    1. Filter by activity level or member count.
    2. Click `Join Community` to request access.
  </Tab>
  <Tab title="Recommended Projects" icon="star">
    Browse the `Recommended` tab on the dashboard.
    
    Featured projects appear based on your profile interests.
  </Tab>
</Tabs>

## Initial Profile Setup

Customize your profile to maximize connections.

<Steps>
  <Step title="Update Profile" icon="settings">
    Go to `Profile > Edit` and add:
    
    - Bio highlighting your open source experience
    - LinkedIn or GitHub links
  </Step>
  <Step title="Set Preferences" icon="sliders">
    In `Settings > Preferences`:
    
    - Choose notification types (email, in-app)
    - Select interest categories (e.g., "SaaS", "DevTools")
  </Step>
  <Step title="Connect Accounts" icon="link">
    Link GitHub via `Integrations` for automatic contribution tracking.
  </Step>
</Steps>

<Expandable title="Advanced Profile Tips" default-open="false">
  Upload a professional avatar (PNG, `<512KB`).
  
  Set visibility preferences: public for networking, private for selective sharing.
</Expandable>
