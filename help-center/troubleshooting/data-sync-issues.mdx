---
title: Data Sync Issues
description: Troubleshoot COSSA data not syncing.
---

## Symptoms

- Recent updates are missing
- Dashboard data is outdated

## Causes

- Network interruptions
- Disabled integrations

## Solution

<Steps>
  <Step title="Check network connection">
    ````bash
    ping cossa.org
    ````
  </Step>
  <Step title="Re-authenticate integrations">
    Go to Integrations page, click "Reconnect" for any disconnected service.
  </Step>
  <Step title="Contact support">
    If issues persist, email support@cossa.org with error details.
  </Step>
</Steps>
