## Overview

Secure your COSSA account with multiple login options, role-based permissions, and API tokens for programmatic access. You control access through email/password, OAuth providers, and two-factor authentication (2FA). API tokens enable seamless integrations while maintaining strict security.

<Callout kind="alert">
Protect your credentials. Never share API tokens or passwords. Use environment variables for production integrations.
</Callout>

COSSA supports flexible login options. Choose the method that fits your workflow.

## Enable Two-Factor Authentication

Activate 2FA to add an extra security layer. Follow these steps:

<Steps>
  <Step title="Access Settings" icon="settings">
    Log in and navigate to **Account > Security**.
  </Step>
  <Step title="Enable 2FA" icon="shield">
    Click **Enable Two-Factor** and scan the QR code with your authenticator app (e.g., Google Authenticator).
  </Step>
  <Step title="Verify" icon="check-circle">
    Enter the 6-digit code from your app to confirm.
  </Step>
</Steps>

## API Access Tokens

Generate tokens for server-to-server integrations. Tokens inherit your user permissions.

### Generate a Token

<CodeGroup tabs="JavaScript,Python,cURL">
  ```javascript
  const response = await fetch('https://api.example.com/tokens', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${YOUR_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ name: 'My Integration Token' })
  });
  const { token } = await response.json();
  console.log(token);
  ```
  ```python
  import requests

  response = requests.post(
      'https://api.example.com/tokens',
      headers={
          'Authorization': f'Bearer {YOUR_API_KEY}',
          'Content-Type': 'application/json'
      },
      json={'name': 'My Integration Token'}
  )
  token = response.json()['token']
  print(token)
  ```
  ```bash
  curl -X POST https://api.example.com/tokens \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"name": "My Integration Token"}'
  ```
</CodeGroup>

## Security Best Practices

Follow these guidelines to keep your account safe.

<ExpandableGroup>
  <Expandable title="Rotate Tokens Regularly" default-open="true">
    Revoke and regenerate tokens every 90 days or after potential exposure.

    ```bash
    curl -X DELETE https://api.example.com/tokens/{token_id} \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Expandable>
  <Expandable title="Account Recovery">
    If locked out, contact support at `support@example.com` with verification details. Enable recovery email in settings first.
  </Expandable>
</ExpandableGroup>
